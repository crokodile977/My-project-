Симуляция распространения ЭМ-волн

Интерактивное приложение для визуализации распространения электромагнитных волн внутри закрытого помещения с учётом стен, мебели и материалов.

О проекте

Школьный проект, моделирующий, как Wi-Fi или радиосигнал распространяется в замкнутом пространстве. Приложение наглядно показывает отражения, затухание и влияние препятствий на качество сигнала.

Возможности

📡

Источник сигнала

Настройка положения, частоты и мощности передатчика.

🧱

Препятствия

Стены и мебель с разными коэффициентами поглощения.

🔥

Тепловая карта

Визуализация интенсивности сигнала по всему помещению.

↩️

Отражения

Упрощённая модель отражения и затухания волн.

Демонстрация

Упрощённая анимация волн от источника внутри комнаты

Технологии

Python Pygame NumPy Matplotlib

Как запустить

pip install -r requirements.txt
python main.py
